# Workflow Builder

A visual workflow / logic builder inspired by tools like n8n and Node-RED.

Users can create workflows using drag-and-drop nodes, connect them visually,
and simulate execution with conditional branching.

## ✨ Features

- Drag & drop node editor (React Flow)
- Trigger, Action, Condition, and End nodes
- Conditional branching (true / false)
- Execution simulation with visual highlighting
- Undo / Redo support
- Save & Load workflows (JSON)
- Dark mode UI

## 🛠 Tech Stack

- React
- Vite
- @xyflow/react (React Flow)
- JavaScript
